# Contributing

Bug reports, ideas and pull requests are welcome at
<https://github.com/Bluerrror/DWDPheno/issues>.

## Development setup

```bash
git clone https://github.com/Bluerrror/DWDPheno
cd DWDPheno
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -e ".[test,plot]"
pytest                 # offline tests (DWD responses are served from tests/fixtures)
pytest -m network      # one small live download from opendata.dwd.de
```

## Guidelines

- Keep the dependencies to `pandas` and `numpy` (`matplotlib` stays optional) and use the
  standard library for HTTP.
- Keep the column names and their order stable: they are part of the public API.
- The package must work with pandas 1.5 through 3.x (copy-on-write, default string dtype) and
  Python 3.9+.
- Every behaviour change needs a test. Tests must run offline: add a trimmed real DWD file to
  `tests/fixtures/` and route its URL in `tests/conftest.py`.
- Update `CHANGELOG.md`.

## Reference data

`dwdpheno/data/` (administrative boundaries and places) is generated by
`python tools/build_data.py`, which downloads BKG VG2500 and the GeoNames dump. Commit the
regenerated files together with a note in the changelog.

## Releasing

1. Bump `__version__` in `dwdpheno/__init__.py`, update `CHANGELOG.md` and `CITATION.cff`.
2. Create a GitHub release; the `publish` workflow builds the package and uploads it to PyPI
   (trusted publishing).
